# Go TCP Chat

A simple TCP client-server application written in Go.

## Features

- TCP server listening on port 8080
- Multiple client support using goroutines
- Bidirectional communication
- Echo responses from server

## Running

### Start server

go run server.go

### Start client

go run client.go

## Example

Client:
Hello

Server:
Received message: Hello

Client:
Echo: Hello
